📖 章导读

化学反应是化学的动词——研究"物质怎么变成另一种物质"。这一章教你三件核心事：
① 如何用化学方程式描述反应，并配平它；
② 如何把反应分类为 5 种基本类型；
③ 水溶液中的反应（沉淀、酸碱中和），以及如何写净离子方程式。

🌟 为什么关键？

第 11 章的所有摩尔计算、第 12 章的化学计量 (Stoichiometry)，都从一根已配平的化学方程式开始。学不会配平，就无法定量分析反应。

§10.1 Reactions and Equations 反应与化学方程式（重难点！）

1. 化学反应发生的信号

① 颜色变化（如铁生锈变棕）
② 产生气体（冒泡）
③ 产生沉淀 (precipitate)
④ 温度变化（放热/吸热）
⑤ 发光
出现一种或多种信号 → 大概率是化学反应，最终以"是否有新物质生成"为准。

2. 化学方程式三种表达

  • Word equation 文字式：hydrogen + oxygen → water
  • Skeleton equation 骨架式：H₂ + O₂ → H₂O（未配平）
  • Balanced equation 配平式：2H₂ + O₂ → 2H₂O

3. 状态符号 & 催化剂

状态：(s) solid、(l) liquid、(g) gas、(aq) 溶于水的水溶液。
可逆反应用双箭头 ⇌。
催化剂写在箭头上方：$\text{2H}_2\text{O}_2 \xrightarrow{\text{MnO}_2} 2\text{H}_2\text{O} + \text{O}_2$

4. 配平 5 步法（Balancing Equations）

第 1 步：写出骨架式（反应物 → 生成物）。
第 2 步：逐元素数原子。
第 3 步：用系数（coefficient）调整——注意：只改系数，永远不改下标！
第 4 步：从最复杂的分子/只出现一次的元素开始；H 和 O 放最后。
第 5 步：检查所有元素两边相等，且系数是最简整数比。
例：配平 C₃H₈ + O₂ → CO₂ + H₂O（丙烷燃烧）
1C：左 3，右 1 → CO₂ 系数写 3。C₃H₈ + O₂ → 3CO₂ + H₂O
2H：左 8，右 2 → H₂O 系数 4。C₃H₈ + O₂ → 3CO₂ + 4H₂O
3O：右 3×2 + 4×1 = 10；左 2 → O₂ 系数 5。
4结果：C₃H₈ + 5O₂ → 3CO₂ + 4H₂O。检查：C 3=3、H 8=8、O 10=10 ✓
7 种常见"双原子分子"必须记住（写单质时不能只写一个原子）：H₂、N₂、O₂、F₂、Cl₂、Br₂、I₂。

§10.2 Classifying Chemical Reactions 反应分类（5 种）

1. 化合反应 Synthesis / Combination：A + B → AB

$2\text{H}_2 + \text{O}_2 \to 2\text{H}_2\text{O}$
$\text{CaO} + \text{H}_2\text{O} \to \text{Ca(OH)}_2$
$\text{N}_2 + 3\text{H}_2 \to 2\text{NH}_3$（合成氨）

2. 分解反应 Decomposition：AB → A + B

$2\text{H}_2\text{O} \xrightarrow{\text{电解}} 2\text{H}_2 + \text{O}_2$
$\text{CaCO}_3 \xrightarrow{\Delta} \text{CaO} + \text{CO}_2$（石灰石煅烧）
$2\text{KClO}_3 \xrightarrow{\text{MnO}_2, \Delta} 2\text{KCl} + 3\text{O}_2$

3. 单置换反应 Single-Replacement：A + BC → AC + B

一种较活泼的单质"顶替"化合物中的另一种。

活动性顺序表 (Activity Series)
金属：K > Ca > Na > Mg > Al > Zn > Fe > Sn > Pb > (H) > Cu > Ag > Au
卤素：F > Cl > Br > I
规则：活性强的能置换活性弱的，反之不能。
$\text{Zn} + 2\text{HCl} \to \text{ZnCl}_2 + \text{H}_2$（Zn 在 H 前，能置换 H₂）
$\text{Cu} + 2\text{AgNO}_3 \to \text{Cu(NO}_3)_2 + 2\text{Ag}$（Cu 比 Ag 活泼）
$\text{Cu} + \text{HCl} \to $ 无反应（Cu 在 H 后）
$\text{Cl}_2 + 2\text{NaBr} \to 2\text{NaCl} + \text{Br}_2$（卤素置换）

4. 复分解反应 Double-Replacement：AB + CD → AD + CB

两种化合物"交换"离子。发生条件：至少产生沉淀、气体、水（弱电解质）之一。

$\text{AgNO}_3 + \text{NaCl} \to \text{AgCl}\downarrow + \text{NaNO}_3$（生成沉淀）
$\text{HCl} + \text{NaOH} \to \text{NaCl} + \text{H}_2\text{O}$（生成水，酸碱中和）
$2\text{HCl} + \text{CaCO}_3 \to \text{CaCl}_2 + \text{H}_2\text{O} + \text{CO}_2\uparrow$（生成气体）

5. 燃烧反应 Combustion：燃料 + O₂ → CO₂ + H₂O

烃或含 C、H 的燃料在足量 O₂ 下完全燃烧生成 CO₂ 和 H₂O；不足 O₂ 时不完全燃烧生成 CO 或 C（黑烟）。

$\text{CH}_4 + 2\text{O}_2 \to \text{CO}_2 + 2\text{H}_2\text{O}$（甲烷完全燃烧）
$2\text{C}_8\text{H}_{18} + 25\text{O}_2 \to 16\text{CO}_2 + 18\text{H}_2\text{O}$（辛烷/汽油）

§10.3 Reactions in Aqueous Solutions 水溶液中的反应

1. 电解质与解离

电解质 electrolyte：溶于水或熔融时能电离产生离子的物质。强电解质（可溶盐、强酸 HCl H₂SO₄ HNO₃…、强碱 NaOH KOH…）在水中完全解离；弱电解质（弱酸弱碱、水）部分解离。

2. 溶解度规则 Solubility Rules（必背！）

常见"可溶"规则：
① 所有 Group 1（Na⁺、K⁺、Li⁺）和 NH₄⁺ 的盐——都可溶。
② 所有 NO₃⁻、CH₃COO⁻（乙酸根）盐——都可溶。
③ Cl⁻、Br⁻、I⁻ 盐——多数可溶，例外：AgCl、PbCl₂、Hg₂Cl₂ 不溶。
④ SO₄²⁻ 盐——多数可溶，例外：BaSO₄、PbSO₄、SrSO₄、CaSO₄（微溶）不溶。
常见"不溶"规则：
⑤ OH⁻ 盐——大多不溶，例外：Group 1、Ba(OH)₂、Sr(OH)₂ 可溶，Ca(OH)₂ 微溶。
⑥ S²⁻ 盐——大多不溶，例外：Group 1、2、NH₄⁺ 可溶。
⑦ CO₃²⁻、PO₄³⁻ 盐——大多不溶，例外：Group 1、NH₄⁺。

3. 三种方程式表达（重点！）

以 AgNO₃ + NaCl → AgCl↓ + NaNO₃ 为例：
① 分子方程式 (molecular equation)：
$\text{AgNO}_3\text{(aq)} + \text{NaCl(aq)} \to \text{AgCl(s)} + \text{NaNO}_3\text{(aq)}$

② 完全离子方程式 (complete ionic)：把所有强电解质写成离子（沉淀、水、气体和弱电解质保留分子式）
$\text{Ag}^+ + \text{NO}_3^- + \text{Na}^+ + \text{Cl}^- \to \text{AgCl(s)} + \text{Na}^+ + \text{NO}_3^-$

③ 净离子方程式 (net ionic)：去掉两边都出现的观察者离子 (spectator ion)
$\text{Ag}^+ + \text{Cl}^- \to \text{AgCl(s)}$
这就是"反应真正发生的过程"。

4. 常见类型：沉淀、气体、酸碱中和

沉淀：Pb(NO₃)₂ + 2KI → PbI₂↓（黄色）+ 2KNO₃　（净离子：Pb²⁺ + 2I⁻ → PbI₂）
气体：Na₂CO₃ + 2HCl → 2NaCl + H₂O + CO₂↑　（净离子：CO₃²⁻ + 2H⁺ → H₂O + CO₂）
酸碱中和：HCl + NaOH → NaCl + H₂O　（净离子：H⁺ + OH⁻ → H₂O）

📝 Study Guide 章节复习

配平：只改系数不改下标；从复杂/单出现元素开始；H、O 最后。
5 种反应：化合 A+B→AB；分解 AB→A+B；单置换（看活动性顺序）；复分解（产生沉淀/水/气体）；燃烧（+O₂ → CO₂ + H₂O）。
水溶液：强电解质完全解离；溶解度规则记熟；净离子式 = 分子式 → 完全离子式 → 划去观察者离子。
7 种双原子分子：H₂ N₂ O₂ F₂ Cl₂ Br₂ I₂。

🧪 Chapter Assessment 章末测评（精选题）

  1. 配平：Fe + O₂ → Fe₂O₃
    4Fe + 3O₂ → 2Fe₂O₃。Fe：4=2×2；O：6=2×3。
  2. 配平：Al + HCl → AlCl₃ + H₂
    2Al + 6HCl → 2AlCl₃ + 3H₂。Al 2=2；Cl 6=6；H 6=6。
  3. 配平：C₄H₁₀ + O₂ → CO₂ + H₂O（丁烷燃烧）
    2C₄H₁₀ + 13O₂ → 8CO₂ + 10H₂O。C 8=8；H 20=20；O 26=16+10=26。
  4. 判断下列反应是否发生并简述：
    ① Cu + FeSO₄ → ？
    ② Zn + CuSO₄ → ？
    ③ Cl₂ + KBr → ？
    ④ I₂ + NaCl → ？
    ① 不反应：Cu 活性弱于 Fe，不能置换。
    ② 反应：Zn + CuSO₄ → ZnSO₄ + Cu（Zn 比 Cu 活泼）。
    ③ 反应：Cl₂ + 2KBr → 2KCl + Br₂（Cl 比 Br 活泼）。
    ④ 不反应：I 比 Cl 弱，不能置换。
  5. 下列反应属于哪一类？
    ① 2Mg + O₂ → 2MgO
    ② CaCO₃ → CaO + CO₂
    ③ Ca(OH)₂ + 2HCl → CaCl₂ + 2H₂O
    ④ CH₄ + 2O₂ → CO₂ + 2H₂O
    ⑤ Fe + CuSO₄ → FeSO₄ + Cu
    ① 化合 (combination)
    ② 分解 (decomposition)
    ③ 复分解/酸碱中和 (double-replacement / neutralization)
    ④ 燃烧 (combustion)
    ⑤ 单置换 (single-replacement)
  6. 预测反应：AgNO₃(aq) + NaCl(aq) → ？写分子、完全离子、净离子方程式。
    生成 AgCl 沉淀（Cl⁻ 盐 Ag 例外）。
    分子：AgNO₃ + NaCl → AgCl(s) + NaNO₃
    完全离子：Ag⁺ + NO₃⁻ + Na⁺ + Cl⁻ → AgCl(s) + Na⁺ + NO₃⁻
    净离子：Ag⁺ + Cl⁻ → AgCl(s)（Na⁺、NO₃⁻ 是观察者离子）
  7. 下列盐水溶液中，会与 Na₂CO₃ 反应生成沉淀的是（　　）：
    a) KNO₃；b) NaCl；c) CaCl₂；d) NH₄Cl。
    选 c。Ca²⁺ + CO₃²⁻ → CaCO₃↓。其余组合的产物都可溶。
  8. 为什么"改下标"不算配平？举例说明。
    改下标就换了一种物质。例如 H₂ + O₂ → H₂O 不平衡，若把 H₂O 改成 H₂O₂ 变成 "H₂ + O₂ → H₂O₂"，看似平衡了，但生成物已经变成过氧化氢，不再是水。因此配平只能加系数。
  9. 写出下列反应的净离子方程式：
    HNO₃(aq) + KOH(aq) → KNO₃(aq) + H₂O(l)
    完全离子：H⁺ + NO₃⁻ + K⁺ + OH⁻ → K⁺ + NO₃⁻ + H₂O
    去 K⁺、NO₃⁻ 观察者：H⁺ + OH⁻ → H₂O。这是所有强酸强碱中和反应的净离子式。
  10. 2H₂O(l) 电解生成 H₂ 和 O₂。配平并注明这是何种反应类型。
    2H₂O(l) → 2H₂(g) + O₂(g)。分解反应（一种物质变成两种或多种）。
  11. 下列盐在水中溶解度大的一组是（　　）：
    a) AgCl, PbSO₄；b) NaNO₃, KCl；c) BaSO₄, CaCO₃；d) Fe(OH)₃, PbI₂。
    选 b。NaNO₃、KCl 都是 Group 1 + NO₃⁻/Cl⁻ 组合，可溶。a、c、d 都为常见沉淀。
  12. Pb(NO₃)₂ 与 KI 混合出现什么颜色沉淀？写净离子方程式。
    生成亮黄色 PbI₂ 沉淀（"金雨 golden rain"）。
    净离子：Pb²⁺ + 2I⁻ → PbI₂(s)
  13. 为什么 CH₄ 完全燃烧生成 CO₂ 和 H₂O？不完全燃烧生成什么？
    O₂ 足量时，C 被氧化到最高价 → CO₂，H → H₂O。O₂ 不足时，C 被氧化到较低价 → CO（有毒！）甚至 C 单质（黑烟）。所以厨房要保持通风，避免煤气不完全燃烧产生 CO 中毒。

⚡ 一页知识卡

5 种反应类型速查

① 化合　A + B → AB
② 分解　AB → A + B
③ 单置换　A + BC → AC + B　（看活动性顺序）
④ 复分解　AB + CD → AD + CB　（沉淀 / 水 / 气体三选一）
⑤ 燃烧　燃料 + O₂ → CO₂ + H₂O

配平口诀
"只改系数不动下标；
先难后易，先大后小；
氢氧最后，检查一遍；
系数化简，最简整数。"
金属活动性（前 12 位）
K > Ca > Na > Mg > Al > Zn > Fe > Sn > Pb > (H) > Cu > Ag > Au
"钾钙钠镁铝，锌铁锡铅氢，铜银金"
溶解度速查（简版）
可溶：Group 1、NH₄⁺、NO₃⁻、CH₃COO⁻ 的盐
Cl⁻/Br⁻/I⁻ 除 Ag/Pb/Hg 都可溶
SO₄²⁻ 除 Ba/Pb/Sr/Ca 都可溶
不溶（除 Group 1 与 NH₄⁺ 外）：OH⁻、S²⁻、CO₃²⁻、PO₄³⁻ 的盐
易错三提醒： ① 单质要用双原子分子写：H₂、N₂、O₂、F₂、Cl₂、Br₂、I₂。
② 状态符号别忘：(s)(l)(g)(aq)。
③ 净离子式：只保留"沉淀 / 弱电解质 / 气体"的分子形式；强电解质拆成离子。
